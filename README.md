🧰 MultiTool Web App

Este projeto é uma aplicação web multifuncional que reúne três ferramentas essenciais em um só lugar:

🧮 Calculadora
📝 Bloco de Notas
💱 Conversor de Moedas (Real → Dólar / Euro)

Desenvolvido com HTML, CSS e JavaScript, o objetivo é oferecer praticidade ao usuário e, ao mesmo tempo, consolidar conhecimentos em desenvolvimento front-end e back-end.
